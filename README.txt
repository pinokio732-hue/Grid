GRID v1 - DEMONSTRATION PROTOTYPE
Open the folder in Android Studio, allow Gradle sync, then Build > Build APK(s).
The generated debug APK is typically at app/build/outputs/apk/debug/app-debug.apk.
This prototype uses LOCAL storage only. The login is DEMONSTRATION ONLY and does not authenticate users securely. Do not use real passwords.
There is NO multi-device synchronization, backend, or real per-user access control yet.
The app supports adding work, dates, statuses, notes and small photos stored locally.
